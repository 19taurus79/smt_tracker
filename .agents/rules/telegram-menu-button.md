# Правило Telegram Bot: Сохранять системное меню команд ([/] Menu)

## СТРОГОЕ ПРАВИЛО:
**НИКОГДА не заменять системную кнопку меню чата на кнопку открытия Web App (`type: "web_app"`, например «⚡️ Трекер»).**

### Обоснование:
Когда у бота вызывается `setChatMenuButton` с `type: "web_app"`, Telegram скрывает стандартную кнопку меню `[/]` (Список команд) и заменяет её одной монопольной кнопкой Web App. 
В результате атлеты и пользователи теряют доступ к списку команд бота (`/start`, `/app`, `/results`, `/rules`, `/coach`, `/help`).

### Требования к коду:
1. Кнопка меню в левом нижнем углу чата Telegram **ВСЕГДА** должна оставаться списком команд:
   ```javascript
   await tgApi("setChatMenuButton", {
     menu_button: {
       type: "commands",
     },
   });
   ```
2. Открытие Mini App трекера (TMA) должно осуществляться:
   - Через инлайн-кнопки в сообщениях (`inline_keyboard` с `web_app: { url }`);
   - Через команду `/app` или `/start`.
3. Запрещено вызывать `ensureTrackerMenuButton` или любые функции, устанавливающие `menu_button: { type: "web_app" }`.
